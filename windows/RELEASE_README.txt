Nestling for Windows (x64)

Extract the entire ZIP into a folder, then run baby_app.exe. Keep the DLLs
and data folder beside the executable. Flutter and Visual Studio are not needed.

To sync with a phone, keep Nestling open on both devices on the same local
network. Allow Nestling through Windows Firewall on private networks when
prompted. In the phone's Settings, scan the PC's pairing QR code, or use
Type code with the PC's address and code. The PC can also pair by typing
the phone's address and code. Use the same feature version on both devices.

Wi-Fi pairing, automatic incremental syncing, edits, deletions and address
rediscovery use the same logic as Android. Syncing continues while the app
is open, including when minimized; closing the Windows app stops syncing.
The PC can display QR codes, but camera scanning is only available on phones.

App data is saved separately from this folder. To update, close Nestling
and extract the new release into a new folder. Windows has no in-app updater.
